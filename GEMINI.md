# Project Guidelines & Rules

## Frontend Design & UI Principles
Whenever any task involves frontend design, UI development, layout styling, components, or user interface reshaping:
- **Mandatory Skill Activation**: Always activate and strictly follow the [`frontend-design`](.agents/skills/frontend-design/SKILL.md) skill.
- **Distinctive & Intentional Design**:
  1. **Ground in Subject Matter**: Understand the domain, audience, and core job before writing code.
  2. **Two-Pass Workflow**:
     - *Pass 1 (Design Plan)*: Define a compact token system (4–6 hex colors, typography pairings, layout concept with ASCII wireframe, alignment guidelines, and uniqueness principles).
     - *Pass 2 (Critique & Refine)*: Review against common AI clichés (e.g., avoid default warm cream + terracotta, generic SaaS-card kits with identical soft grey shadows, arbitrary all-caps eyebrows, meaningless numbered markers) and revise before building.
  3. **High Quality Floor**: Responsive down to mobile, visible keyboard focus states, reduced motion respected, visual accessibility.
  4. **Intentional Writing & Copy**: Plain language, active voice (e.g., "Save changes" over "Submit"), clear and helpful error / empty states.
